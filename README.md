# Landing – Chatbot Analista de Datos (IT Cancún)

Página estática para presentar el chatbot de minería de datos en GitHub Pages y LinkedIn.

## Cómo publicarla en GitHub Pages

1. Crea un repositorio nuevo (ej. `chatbot-itcancun-demo`).
2. Sube **todo el contenido** de esta carpeta (index.html, css/, js/, assets/, README.md).
3. En el repo: **Settings → Pages → Source: Deploy from a branch → main / root**.
4. En unos minutos tendrás la URL: `https://TU_USUARIO.github.io/chatbot-itcancun-demo/`

## Personalizar

- En `index.html`, busca `id="github-link"` y pon la URL de tu repo del chatbot.
- Las capturas están en `assets/`.

## Estructura

```
index.html
css/style.css
js/main.js
assets/
  chat-maestro.png
  chat-porcentaje.png
  chat-grafica.png
  chat-consulta.png
README.md
```
